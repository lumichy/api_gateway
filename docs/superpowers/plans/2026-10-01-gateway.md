# Subscription Gateway Implementation Plan

Goal: Deliver a runnable single-user OpenAI-compatible text gateway with subscription adapters, persistent quota state and bounded failover.
Architecture: Native Node HTTP, SQLite state, async-generator adapters and capability-aware scheduler. TypeScript is executed by Node 24 type stripping. No package install required.
Execution: Inline core implementation with isolated adapter implementation and independent review, as required by the implementation/review skills. This empty directory is not a Git repository, so commits and worktrees do not apply.
